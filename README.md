# myfeeds.sgit.ai

> **Feeds are replaceable. Your reading is not.**

The site for [myfeeds.sgit.ai](https://myfeeds.sgit.ai), a member of the
[sgit.ai network](https://sgit.ai/network/index.md). It argues that the record of what you
read — not the articles, which the publisher will serve again tomorrow — is the valuable,
unrecoverable half of a feed reader, and that it belongs in an encrypted vault you hold.

It publishes the `read-state/v1` contract **before** any implementation exists, which is
the estate's convention: a commitment published early is checkable later, by anyone.

**Nothing here is a running service.** What does not exist yet is listed, in build order,
at [`/build-order/`](build-order/index.md).

```
team/board/*.md                            the board

```

## Build

```bash
python3 admin/build/build_pages.py && node admin/build/validate.js
```

Python 3.11+ and Node 22+; no dependencies in either. The validator is the release gate —
it fails the build on a broken internal link, a missing or thin markdown twin, a page that
would render blank inside a vault frame, a status marker outside the fixed vocabulary, an
orphan page, a role without an exclusion list, or a board card owned by a role that does
not exist. CI additionally rebuilds on a clean checkout and fails if the committed output
differs by a byte.

**Do not edit the generated tree.** Editing `index.html` is a change the next build erases
and the validator cannot catch, because it checks the output against the content rather
than against your intention. See [`/admin/`](admin/index.md) for the authoring contract.

## The team

The site is built and run by seven AI agent roles under one human owner, published in the
open at [`/team/`](team/index.md): a Conductor that does no work, and the portable core —
Architect, Dev, DevOps, QA, Librarian, Historian — that
[teams.sgit.ai](https://teams.sgit.ai/roster/index.html) measured three independent teams
reaching for. Each role is a file, `team/roles/<slug>/ROLE.md`, carrying the failure
condition it is judged on and the exclusion list that makes it a role rather than a general
agent. The site's team pages and `data/team.json` are generated from those files, so the
site cannot describe a role the repository does not carry.

Start a role by pasting the matching prompt from
[`team/prompts/README.md`](team/prompts/README.md) into a fresh agent.
